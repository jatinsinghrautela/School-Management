Copy this into a protected operator record; fill release revision, host/school, date, reviewer and evidence references. No credentials/pupil details/exports. Unchecked gates mean real-data release has not been accepted.

- [ ] Clean revision and passing `release:verify` report recorded.
- [ ] Actual-host runtime grants, migration/recovery separation and network/secrets checked.
- [ ] Trusted HTTPS/DNS, forwarded headers, private Node/MySQL, CSP and printed documents verified.
- [ ] Supervisor shutdown/restart and actionable outage handling tested.
- [ ] Real MySQL capacity and disk/quota thresholds measured with synthetic data.
- [ ] SMTP/scanner explicitly disabled or real delivery/rejection acceptance completed.
- [ ] Actual-host restore, recovery objectives, off-device encrypted copy, key custody/retention approved.

- [ ] Reviewed access/correction/erasure process exercised, including snapshots/audits/shared records/backups.
